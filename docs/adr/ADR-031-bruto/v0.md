Golden set de 60 perguntas, avaliadas **só nas 54 com `no_recorte` = sim** (índice de 79 páginas); juiz Gemma 4 26B-A4B ([ADR-028](../../docs/adr/ADR-028-metricas-com-juiz-local.md)), métricas mecânicas do [ADR-029](../../docs/adr/ADR-029-metricas-mecanicas.md). O mesmo LLM de resposta (Qwen3.6, temperatura 0,2) e o mesmo prompt em A1 a A3r.
